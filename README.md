# Theo Odawara

<img width="100%" height="3" src="https://capsule-render.vercel.app/api?type=rect&color=8B949E" alt=""/>

Backend developer. I build REST APIs with **NestJS and TypeScript** — PostgreSQL with TypeORM, Redis, RabbitMQ, Docker, deployed with Coolify and Traefik — and I'm moving more of that work to **Rust**.

Co-founder of [ATNexusLab](https://github.com/ATNexusLab) with Alex, where we build products end to end.

### Projects

- [**clinicore**](https://github.com/TheoOdawara/clinicore) — dental clinic SaaS. Complete authentication API, now being migrated from NestJS to Rust (axum + sqlx) without changing the HTTP contract.
- [**Kiri**](https://github.com/TheoOdawara/Kiri) — async Rust coding-agent harness: streaming tool-call loop, OS-level sandboxing on Windows, macOS and Linux.
- [**Vultra**](https://github.com/TheoOdawara/Vultra) — facial-recognition class attendance with vector embeddings, LGPD-compliant. Undergraduate research.
